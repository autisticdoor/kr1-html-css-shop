# kr1-html-css-shop — SkinShop

Учебный frontend-проект по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина игровых скинов «SkinShop». Товары, цены и контакты вымышленные. Проект выполнен без CSS-фреймворков, JavaScript используется только для модального окна и проверки форм.

## Ссылка на опубликованный проект

GitHub Pages: https://autisticdoor.github.io/kr1-html-css-shop/

## Краткое описание проекта

Сайт состоит из пяти страниц: главная, каталог, карточка товара, заявка и контакты. На всех страницах одинаковые шапка с меню и подвал. Оформление вынесено во внешний файл `css/style.css`.

## Структура проекта

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | hero-блок, преимущества, популярные товары, информационный блок |
| `catalog.html` | карточки товаров, категории, статический блок фильтров |
| `product.html` | изображение (заглушка), описание, характеристики, цена, кнопка заявки |
| `order.html` | форма оформления заявки |
| `contacts.html` | контактная информация, форма обратной связи, ссылка на страницу заявки |

## Что реализовано

- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация и якорные ссылки (`index.html#advantages`, `index.html#popular`, `#contacts`);
- карточки товаров с названием, описанием, ценой, кнопкой «Подробнее» и бейджами;
- таблицы с `caption`, `thead`, `tbody`, `th`, `td`;
- формы с `label`, `for`/`id`, `name`, `required`, `type="email"`;
- модальное окно на элементе `<dialog>`;
- CSS-переменные, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox (шапка, меню, группы кнопок, подвал) и CSS Grid (карточки, каталог, раскладка страниц);
- БЭМ-именование классов (`product-card__title`, `product-card--discount`, `order-form__field`);
- позиционирование: `relative` (карточка), `absolute` (бейдж), `sticky` (шапка и фильтры), `fixed` (кнопка «Наверх»), `z-index`.

## Самостоятельные доработки

- тема магазина игровых скинов с категориями товаров;
- бейджи «Хит», «Новинка» и скидка на карточках, старая цена у товаров со скидкой;
- вторая таблица на странице товара — сравнение версий скина;
- sticky-блок фильтров в каталоге и фиксированная кнопка «Наверх»;
- простая адаптивность для узких экранов.
