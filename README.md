# kr1-html-css-shop — SkinShop (магазин скинов для CS2)

Учебный frontend-проект по дисциплине «Фронтенд и бэкенд разработка».

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина игровых скинов «SkinShop». Названия скинов и их характеристики взяты из Counter-Strike 2, цены и контакты условные (магазин учебный и не связан с Valve). Проект выполнен без CSS-фреймворков, JavaScript используется только для модального окна и проверки форм.

## Ссылка на опубликованный проект

GitHub Pages: https://autisticdoor.github.io/kr1-html-css-shop/

## Краткое описание проекта

Сайт состоит из пяти страниц: главная, каталог, карточка товара, заявка и контакты. На всех страницах одинаковые шапка с меню и подвал. Оформление вынесено во внешний файл `css/style.css`.

## Что реализовано

- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация и якорные ссылки (`index.html#advantages`, `index.html#popular`, `#contacts`);
- карточки товаров с названием, описанием, ценой, кнопкой «Подробнее» и бейджами;
- таблицы с `caption`, `thead`, `tbody`, `th`, `td`;
- формы с `label`, `for`/`id`, `name`, `required`, `type="email"`;
- модальное окно на элементе `<dialog>`;
- CSS-переменные, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox (шапка, меню, группы кнопок, подвал) и CSS Grid (карточки, каталог, раскладка страниц);
- БЭМ-именование классов (`product-card__title`, `product-card--discount`, `order-form__field`);
- позиционирование: `relative` (карточка), `absolute` (бейдж), `sticky` (шапка и фильтры), `fixed` (кнопка «Наверх»), `z-index`.

## Самостоятельные доработки

Выбраны четыре улучшения из списка в методических указаниях.

1. **Изменение структуры интерфейса.** Главная: первый экран в две колонки (текст и карточка «Скин дня», Grid). Страница товара: основной контент слева и липкая панель покупки справа (`.product-page`, `.buy-panel`, `position: sticky`). Страница заявки: блок «Ваш заказ» с выбранным скином и ценой.
2. **Собственное визуальное оформление — тёмная тема.** Все цвета заданы CSS-переменными в `:root` (фон, поверхности, текст, ссылки, границы), включён `color-scheme: dark`, чтобы поля и окно выглядели тёмными. Верхняя рамка карточек окрашена по качеству скина CS2 (Запрещённое, Засекреченное, Тайное, Контрабанда), у карточек есть подсветка при наведении.
3. **Дополнительные карточки товаров.** В каталоге 8 реальных скинов CS2: AK-47 | Redline, AWP | Asiimov, M4A4 | Howl, USP-S | Kill Confirmed, Desert Eagle | Blaze, Glock-18 | Fade, ★ Karambit | Doppler, AWP | Dragon Lore. В карточках указаны качество и диапазон износа (float), на странице товара — таблица характеристик (оружие, качество, коллекция, контейнер, float, StatTrak™, год выхода) и таблица цен по износу. В фильтры добавлена категория «Качество».
4. **Доработка форм, сообщений и пользовательских сценариев.** Ошибки показываются под полями на русском языке; маска телефона `+7 (900) 000-00-00`; необязательное поле «Ссылка для обмена в Steam»; товар можно передать в адресе (`order.html?product=...`), поэтому кнопка «Оставить заявку» на странице товара сразу выбирает скин; уведомление об отправке с названием товара пропадает через 6 секунд.

Остальное: бейджи «Хит», «Новинка» и скидка, старая цена, sticky-фильтры, кнопка «Наверх», простая адаптивность.

## Источники данных о скинах

Названия, качество, коллекции и диапазоны износа взяты из открытых справочников по CS2 (csgoskins.gg, csdb.gg). Цены в магазине условные и придуманы для учебного проекта. Изображений нет: вместо них стоят текстовые заглушки.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню (`.site-nav__list`);
- Flexbox для внутренней структуры карточек товаров (`.product-card`, `.product-card__actions`);
- CSS Grid для сетки карточек (`.products-grid`);
- CSS Grid для страницы каталога с фильтрами и списком товаров (`.catalog-layout`, области `filters` и `products`).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация (`site-nav__list`, `site-nav__item`, `site-nav__link`, модификатор `site-nav__link--active`);
- `breadcrumbs` — хлебные крошки (`breadcrumbs__link`, `breadcrumbs__current`);
- `hero` — первый экран главной страницы (элементы `hero__content`, `hero__spotlight`);
- `products-grid` — сетка товаров (модификатор `products-grid--catalog`);
- `product-card` — карточка товара (модификаторы `product-card--featured`, `product-card--discount`, `product-card--classified`, `product-card--covert`, `product-card--restricted`, `product-card--contraband`);
- `product-page` и `buy-panel` — страница товара и панель покупки;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` и `filters-form` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки (`order-form__field`, `order-form__label`, `order-form__input`, `order-form__select`, `order-form__textarea`, `order-form__error`);
- `button` — кнопка (модификаторы `button--primary`, `button--secondary`);
- `data-table` — таблицы;
- `site-footer` — подвал сайта.

Стилизация выполняется только по классам: id используются для якорей и JavaScript, inline-стилей нет.
